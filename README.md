# School Project - Bike Website

## Project Overview
This project is a static website created for a school project. It's a simple website to showcase different types of bicycles.

## Key Features & Architecture
*   **Static Website**: The website is built using plain HTML.
*   **Multi-page Structure**: The site has a main `index.html` page and additional pages located in the `pages/` directory.
*   **Organized Assets**: Images and videos are stored in the `images/` and `videos/` directories, respectively.

## Directory Structure
```
├── images/
├── pages/
├── videos/
├── index.html
└── README.md
```

## Getting Started
To view the website, open the `index.html` file in your web browser.

## Dependencies
A modern web browser (e.g., Chrome, Firefox, Edge).
